# 実装計画: 「ポンマス破壊構成モード」および未設定武器の警告表示

## 概要
ユーザーからのご要望に基づき、以下の2つの新機能を追加します。
1. **ポンマス破壊構成モード**: 登録済みの全ウェポンマスター（敵）構成に対して、自身の武器が最も汎用的に勝てる（多くの敵を対策できる）構成を計算し、頻出順で提案するモード。
2. **未設定武器の警告**: ウェポンマスターモードにおいて、構成が1つも登録されていない武器を画面上部に表示する機能。

## 実装内容

### 1. ポンマス破壊構成モード (Weapon Master Destroyer Mode)
*   **UI追加**: `App.jsx` のタブ（総合評価、ターゲット対策、ウェポンマスター）に並ぶ形で、新しいタブまたはモードスイッチ「ポンマス破壊構成モード」を追加します。
*   **ロジック**: 
    *   **解釈案**: 現在登録されている「すべての武器のウェポンマスター構成（`weaponMasterConfigs` 全体）」を仮想的なターゲットプールとして扱い、自分が選択した武器の全組み合わせをシミュレーションします。
    *   計算後、各構成が「どれだけ多くのウェポンマスターに勝てるか（勝率・勝利数）」を基準にソートして提示します。
    *   もしくは、「敵の武器Aに対するトップ3」「敵の武器Bに対するトップ3」…をそれぞれ算出し、「トップ3にランクインした回数（頻度）」が多い順に提示する形の実装とします（「頻出順」という表現に最も適しています）。

### 2. 未登録武器の警告表示
*   **UI追加**: ウェポンマスターモードを開いている間、`weaponMasterConfigs` に1つも構成データが存在しない武器を洗い出し、ページ上部（ヘッダー下など）に「構成が登録されていない武器があります: 〇〇, 〇〇...」と表示します。
