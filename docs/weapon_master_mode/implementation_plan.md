# エクストラエネミー機能 追加計画

ウェポンマスターモードにおいて、自由なパラメータで敵の武器やスキルを定義できる「エクストラエネミー」機能を追加します。

## 変更の概要

### 1. エクストラエネミーのデータ管理
- `App.jsx` に `extraWeapons` ステートを追加し、ユーザーが作成したカスタム武器を管理します。
- これも `localStorage` を使用して永続化します。
- `data.txt` から読み込んだ `weapons` と `extraWeapons` を結合した `allWeapons` を作成し、UIの各プルダウン（使用する武器や敵の武器）で選択できるようにします。
- IDの衝突を避けるため、カスタム武器の `id` には `Date.now()` などの一意な値を使用します。

### 2. UIの追加 (`src/App.jsx`)
- ウェポンマスターモード内に「カスタム武器（エクストラエネミー）を作成」のセクション（またはトグルで開くフォーム）を追加します。
- **入力項目**:
  - 武器名（自由入力テキスト）
  - スキル1〜5のそれぞれについて：
    - スキル名（自由入力テキスト）
    - スキルタイプ（上段、中段、下段、奥義、無形 のプルダウン）
    - 威力 ATK（数値入力）
    - 防御 DEF（数値入力）
    - 使用回数（数値入力）
- 作成されたカスタム武器のリスト表示および削除機能。

### 3. Web Workerとの連携 (`src/simulationWorker.js`)
- 現在 Worker 側は初期化時（`INIT`）に渡された `weapons` しか事前計算していません。
- 新しいメッセージタイプ `UPDATE_EXTRA_WEAPONS` を追加し、`extraWeapons` が作成・削除されるたびに Worker に通知します。
- Worker は受け取った `extraWeapons` に対して `generateValidConfigs` と `resolveConfig` を実行し、既存の計算キャッシュ（`allResolved` など）に追加・更新します。

## 確認事項 (User Review Required)

> [!IMPORTANT]
> **自分が使用する武器としてのエクストラエネミー**
> 今回作成した「エクストラエネミー（カスタム武器）」は、敵として設定するだけでなく、**自分自身が使用する武器としても選択可能（総合評価モード等でも使用可能）**にしてしまってよろしいでしょうか？ （システム上、共通の武器リストに混ぜるのが最も自然で拡張性が高いため、そのように実装する予定です）
