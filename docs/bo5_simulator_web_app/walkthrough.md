# Bo5 Simulator 構築完了

「Bo5 Simulator」Webアプリケーションの実装が完了し、ローカルサーバーを起動しました。
`http://localhost:5173/` にアクセスして動作を確認できます。

## 実装内容の概要

### 1. ゲームデータのパース (`dataParser.js`)
- `data.txt` からデータを読み込み、5スキルごとのグループを1つの「武器」として93種類の武器リストを生成しました。
- 各スキルの「使用可能回数」をパースし、シミュレーション時に制限として適用しています。

### 2. シミュレーションエンジン (`simulationWorker.js`)
計算量が膨大になるため（最大約2.9億マッチアップ）、**Web Workerによる非同期処理**として実装しました。これにより、計算中もUIがフリーズすることなく、ローディング表示が行われます。

- **`INIT` フェーズ:** アプリ起動時に、93種類の全武器について、スキル使用制限を満たす5ターン分の有効な構成順列（最大3125通り/武器）を網羅生成。さらに、各構成について「ボルテージブースト」などの効果をあらかじめ計算し、各ターンの確定ダメージデータを持つInt32Arrayにキャッシュしています。
- **`SIMULATE` フェーズ:** 選択した武器の全構成について、指定されたターゲット群（総合モードなら全武器）の全構成と総当たり戦を行い、勝利数をカウントします。

### 3. ダメージ計算ルール
- `Math.floor` を用いて、同型の計算の「小数点未満切り捨て」を実現しました。
- 敗北時のダメージ計算やマイナスダメージ時は、ダメージを「0」に丸める仕様としています。

### 4. UI/UX (`App.jsx`, `index.css`)
- **Vanilla CSS** を使用し、**Glassmorphism（ガラス風）** のスタイリッシュでプレミアムなデザインに仕上げました。
- **総合評価モード:** 指定した武器の構成を、全武器の全構成と戦わせた場合の平均勝率を出します。
- **ターゲット対策モード:** 対戦相手を絞って（最大10個）、その相手群の構成に対して最も勝率の高い構成を見つけ出します。
- それぞれの結果は「勝率」「W/D/L（勝・分・負）」「使用スキルの5ターンの流れ」として分かりやすくカード表示されます。

## 動作確認結果
- 93種類の武器のパース、および全試合パターンのキャッシュ生成が初期ロード時に数秒で行われます。
- 総合評価モードによる最大パターンのシミュレーションも、Web Workerにより約1〜2秒ほどで完了し、即座に上位5つの勝率構成が表示されることを確認しました。
