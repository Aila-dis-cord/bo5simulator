# Bo5 Simulator 構築計画

「Bo5」の勝率計算Webアプリを構築するための実装計画です。

## User Review Required

> [!IMPORTANT]
> **ダメージ計算仕様の確認**
> - 札が敗北した場合に受けるダメージや、同型によるダメージ計算において、計算結果がマイナスになる場合（例：相手の攻撃力がこちらの防御力より低い場合）は、「ダメージ0（回復しない）」として処理します。
> - 同型の計算における「少数点未満切り捨て」は、`Math.floor` を用いて実装します（負の攻撃力の場合も下の値に丸められます）。
> 
> これらの仕様で問題ないかご確認ください。

## Open Questions

> [!NOTE]
> - 「全武器に対して勝率が高い構成」の勝率は、引き分けをどのように評価しますか？（現状は「勝利数 / 総試合数」を勝率とし、引き分けは勝率に含めず別途表示する方針です）

## Proposed Changes

### 1. プロジェクトのセットアップ
- Vite + React を用いてプロジェクトを初期化します。
- UIのスタイリングには Vanilla CSS を使用し、モダンで洗練されたデザイン（Glassmorphism、ダークモードベース、アニメーション等）を適用します。

### 2. シミュレーションエンジンの構築 (Web Worker)
膨大な構成パターン（最大約3,000構成 × 全武器の約93,000構成 ≒ 2.9億マッチ）を高速に計算するため、Web Worker を用いた非同期処理を実装します。

#### [NEW] `src/simulationWorker.js`
- 武器データのパースおよび全有効構成（スキル使用可能回数を満たす5ターンの順列）の事前生成。
- ボルテージブースト（奥義・無形の攻撃力上昇）の事前計算。
- 指定されたモード（対全武器、または対指定武器群）に応じた総当たり戦の実行と、勝率順のソート。

### 3. データパースと管理
#### [NEW] `src/dataParser.js`
- `data.txt` の内容を読み込み、93種類の武器データ（各5スキル）として構造化します。
- スキルごとに名前、タイプ（上段・中段・下段・奥義・無形）、攻撃力、防御力、使用可能回数を抽出します。

### 4. UIコンポーネントの構築
#### [NEW] `src/App.jsx`
- メインルーティングおよび状態管理。
- 武器選択とモード切り替え（総合評価 / ターゲット対策）。

#### [NEW] `src/components/ModeSelector.jsx`
- 「総合評価モード」と「ターゲット対策モード」のタブ切り替え。

#### [NEW] `src/components/WeaponSelect.jsx`
- 自分の使用する武器を選択するドロップダウン（検索可能）。
- ターゲット武器を複数選択するインターフェース（最大10個）。

#### [NEW] `src/components/RankingDisplay.jsx`
- 上位5個の構成をカード形式で表示。
- 勝率、勝利数/引き分け数/敗北数、5ターンのスキル構成を視覚的にリッチに表示。

#### [NEW] `src/index.css`
- プロジェクト全体に適用する Vanilla CSS。
- ダークテーマ、Glassmorphism、スムーズなトランジション、モダンなタイポグラフィを定義。

## Verification Plan

### Automated Tests
- 実装後にローカル開発サーバー (`npm run dev`) を立ち上げ、シミュレータが正しく機能するか確認します。
- ブラウザ上で特定の武器を選択し、上位5つの構成が数秒以内に結果として表示されるかを検証します（Web Workerのパフォーマンス確認）。

### Manual Verification
- `data.txt` の内容が正しく93個の武器としてパースされているか確認します。
- ボルテージブーストや同型時の半減計算など、特殊なルールが正確にダメージスコアに反映されているか、ログを出力してテストケース検証を行います。
